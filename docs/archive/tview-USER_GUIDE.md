# 启视·TVIEW 用户手册

## 1. 系统要求
- Ubuntu 24.04 LTS（Wayland 会话）
- 8GB 内存（推荐）
- USB 2.4G 遥控器 / 蓝牙遥控器 / 游戏手柄


## 2. 安装
打开终端，执行：
bash <(curl -s https://raw.githubusercontent.com/你的用户名/tview-launcher/main/install.sh)
等待安装完成，重启电脑即可自动进入电视盒子模式。


## 3. 卸载
sudo /opt/tview/uninstall.sh


## 4. 遥控器/手柄操作指南

| 按键 | 功能 |
|------|------|
| 方向键 | 移动焦点 |
| OK/确认键 | 启动应用 / 确认操作 |
| 返回键 | 返回上一级 / 长按 3 秒强制回到主界面 |
| 主页键 | 回到主界面 |
| 音量键 | 控制音量 |
| 电源键（长按） | 关机/重启菜单 |
| 菜单键 | 快捷操作 |

手柄支持：Xbox、PlayStation、Nintendo 手柄即插即用。


## 5. 主界面
- 顶部显示日期和时间
- 中间网格显示应用图标
- 底部两个按钮："设置" + "应用下载"


## 6. 如何安装新应用
1. 遥控器移到 "📦 应用下载"，按确认进入
2. 选择市场（当贝/F-Droid/Google Play）或推荐应用（Kodi/VLC）
3. 自动下载安装（显示进度条）
4. 安装完成后自动出现在主界面网格中


## 7. 如何添加 Linux 原生应用
1. 进入 "设置"
2. 选择 "自定义 Linux 应用"
3. 填写：应用名称、启动命令、图标路径
4. 保存后主界面出现新图标


## 8. 如何切换 WiFi
1. 进入 "设置 → 网络 → WiFi"
2. 自动扫描附近 WiFi
3. 选择目标网络
4. 用虚拟键盘输入密码
5. 等待连接成功提示


## 9. 如何设置固定 IP
1. 进入 "设置 → 网络 → IP 设置"
2. 选择 "手动"
3. 填写 IP、子网掩码、网关、DNS
4. 点击 "应用"


## 10. 如何开启节能模式
1. 进入 "设置"
2. 打开 "节能模式" 开关（默认关闭，需要手动开启才生效）
3. 进入盒子模式时自动关闭 Ubuntu 桌面，节省资源
4. 退出盒子模式时自动恢复


## 11. 如何使用钩子命令（高级功能）
1. 进入 "设置"
2. 找到 "启动时执行" 和 "退出时执行"
3. 填写 Shell 命令（如 docker start jellyfin / docker stop transmission）
4. 进入/退出盒子模式时会自动执行这些命令


## 12. 如何退出电视盒子模式
1. 进入 "设置"
2. 选择 "退出电视盒子模式"
3. 确认后回到 Ubuntu 桌面（节能模式开启则自动恢复桌面）


## 13. 常见问题

Q：遥控器失灵怎么办？
A：检查 USB 接收器是否插好，或按键盘方向键临时操控。

Q：应用卡死退不出来？
A：长按遥控器返回键 3 秒，强制回到主界面。

Q：系统启动后黑屏？
A：按 Ctrl+Alt+F1 切换到 TTY1，输入 sudo systemctl restart tview-launcher.service

Q：如何彻底卸载？
A：执行 /opt/tview/uninstall.sh

Q：WiFi 密码输入不了？
A：使用虚拟键盘：方向键选字母，OK 键输入，返回键删除，长按返回清空全部。
