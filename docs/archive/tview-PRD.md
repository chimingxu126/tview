# 启视·TVIEW —— 产品需求文档 v0.1

## 1. 项目概述
**项目名称**：启视·TVIEW Launcher  
**项目定位**：把 Ubuntu 变成一台由遥控器/手柄操控的电视盒子启动器  
**核心能力**：开机自启、遥控器操控、安卓应用（Waydroid）与 Linux 原生应用统一管理  
**运行环境**：Ubuntu 24.04 LTS（Wayland 会话）  
**技术栈**：Python 3.10 + PyQt5 + Waydroid + evdev + Cage + Systemd


## 2. 核心功能

### 2.1 主界面
- 全屏无边框，深色背景（#1a1a2e）
- 顶部状态栏：日期 + 时间 + 网络状态
- 网格布局显示应用图标（默认 3 列，可调 2~6 列）
- 底部固定按钮：设置 + 应用下载

### 2.2 应用管理
- **安卓应用**：自动读取 Waydroid 已安装应用列表
- **Linux 应用**：用户手动添加自定义应用（名称 + 命令 + 图标路径）
- 统一在网格中展示，用遥控器/手柄操控启动

### 2.3 应用下载（市场）
内置 5 个应用市场/推荐应用，点击后自动检测 → 下载 APK → 显示进度条 → 安装 → 刷新列表：
- 当贝市场（推荐中国用户）
- F-Droid
- Google Play
- Kodi（媒体中心）
- VLC（播放器）

### 2.4 设置界面

| 功能模块 | 说明 |
|----------|------|
| **节能模式** | 默认关闭。开启后杀死 GDM，退出时复活 GDM，降低资源占用 |
| **桌面列数** | 2~6 列可调，默认 3 列，实时生效 |
| **自定义壁纸** | 选择本地图片作为桌面背景 |
| **自定义 Linux 应用** | 添加/删除 Linux 原生应用快捷方式 |
| **开机自启** | 启用/禁用 Systemd 服务 |
| **启动时执行（钩子）** | 进入盒子模式前执行自定义 Shell 命令 |
| **退出时执行（钩子）** | 退出盒子模式时执行自定义 Shell 命令 |
| **退出电视盒子模式** | 回到 Ubuntu 桌面（节能模式开启则复活 GDM） |
| **重启 / 关机** | 系统级控制 |
| **分辨率自适应** | 自动适配显示器最佳分辨率 |
| **USB 唤醒** | 配置遥控器 USB 设备唤醒电脑 |
| **网络配置（IP/掩码/网关/DNS）** | 使用 nmcli 实现 DHCP/手动切换 |
| **代理设置** | HTTP/HTTPS/SOCKS5，带测试连接 |
| **WiFi 切换** | 扫描、选择、虚拟键盘输入密码、连接、忘记网络 |
| **定时关机** | 30分钟/1小时/2小时 |
| **屏保设置** | 无操作 5/10/30 分钟后启动时钟或黑屏 |
| **应用分类** | 按"全部/影音/游戏/工具/儿童"分类 |
| **日志导出** | 一键导出全部日志到用户桌面 |

### 2.5 钩子命令（v0.1 核心特性）
在设置界面提供两个多行文本框：
- **启动时执行（Enter Hook）**：进入电视模式前执行的 Shell 命令
- **退出时执行（Exit Hook）**：退出电视模式时执行的 Shell 命令

用户可在此填写任何 Shell 命令（如启动/停止 Docker 容器、挂载 NAS 硬盘等）。执行结果写入日志，支持超时保护（60 秒）。

### 2.6 支持的操控设备
- USB 2.4G 无线遥控器（核心设备，免驱即插）
- 蓝牙遥控器（需系统配对）
- Xbox / PlayStation / Nintendo 游戏手柄（USB/蓝牙）


## 3. 交互规范

| 按键 | 功能 |
|------|------|
| 方向键 | 移动焦点 |
| 确认键 | 启动应用 / 确认操作 |
| 返回键 | 返回上一级 / 长按 3 秒强制回到主界面 |
| 主页键 | 直接回到主界面 |
| 音量键 | 控制系统音量 |
| 电源键（长按） | 弹出关机/重启菜单 |
| 菜单键 | 快捷操作 |


## 4. 容错与救援机制
- **组合键强制退出**：长按返回键 3 秒 → 强制杀掉当前安卓应用
- **看门狗**：每 30 秒检测 Waydroid 状态，异常自动恢复
- **异常日志**：崩溃后自动写入 `crash.log`
- **安全模式**：连续两次启动失败，第三次自动进入安全模式
- **遥控器掉线**：检测到设备消失时弹窗提示
